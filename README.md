# ടൈംടേബിൾ പ്രോ (Timetable Pro) 📅

രണ്ടു സ്ഥാപനങ്ങൾക്കും അധ്യാപകരുടെ ലഭ്യതയ്ക്കും അനുസൃതമായി ടൈംടേബിൾ ക്രമീകരിക്കാനുള്ള സമ്പൂർണ്ണ ആൻഡ്രോയിഡ് ആപ്ലിക്കേഷൻ.

## 🚀 പ്രധാന സവിശേഷതകൾ (Key Features)

- **👨‍🏫 അധ്യാപക ലഭ്യത പരിശോധന (Teacher Availability):** ദിവസം മുഴുവനായും (Full Day Leave) പിരീഡുകൾ തിരിച്ചും ലഭ്യതക്കുറവ് രേഖപ്പെടുത്താം. ഷെഡ്യൂൾ ചെയ്യുമ്പോൾ തത്സമയം ക്ലാഷ് മുന്നറിയിപ്പുകൾ ലഭിക്കും.
- **👥 ഒരേ ക്ലാസിൽ രണ്ട് ബാച്ചുകൾ (Dual Batches in Same Period):** ഒരേ പിരീഡിൽ ഒരേ ക്ലാസിൽ തന്നെ ബാച്ച് A, ബാച്ച് B എന്ന് തിരിച്ച് രണ്ട് വ്യത്യസ്ത വിഷയങ്ങളും അധ്യാപകരെയും ഷെഡ്യൂൾ ചെയ്യാം.
- **🤝 ഷെയർ അധ്യാപകർ (Shared Classes):** 3 പിരീഡുകളിൽ 1 പിരീഡ് രണ്ടാമതൊരു അധ്യാപകൻ എടുക്കുന്ന രീതിയും കോ-ടീച്ചിംഗ് രീതിയും.
- **🏫 രണ്ട് സ്ഥാപനങ്ങൾ (Multi-Institution Support):** രണ്ട് കോളേജുകളിലും ഒരേ അധ്യാപകൻ പഠിപ്പിക്കുന്നുണ്ടെങ്കിൽ ഒരേ സമയത്ത് ക്രോസ്സ് ക്ലാഷ് വരാതെ സിസ്റ്റം തടയും.
- **⏱️ ദിവസേനയുള്ള പിരീഡ് എണ്ണം (Configurable Periods):** വെള്ളിയാഴ്ച 4 പിരീഡ്, മറ്റ് ദിവസങ്ങളിൽ 6 പിരീഡ് എന്നിങ്ങനെ ഓരോ ദിവസത്തേയും പിരീഡ് എണ്ണം മാറ്റാം.
- **📲 വാട്സ്ആപ്പ് ഷെയറിംഗ് (Export / Share):** ടൈംടേബിൾ വാട്സ്ആപ്പിലോ പ്രിന്ററിലോ പങ്കുവെക്കാൻ അനുയോജ്യമായ ഫോർമാറ്റിൽ കോപ്പി ചെയ്യാം.

## 📱 ഇൻസ്റ്റാളേഷൻ (Installation)

1. [Releases](https://github.com/algaithwafiyya-bit/table-pro/releases) പേജിൽ നിന്ന് ഏറ്റവും പുതിയ `.apk` ഫയൽ ഡൗൺലോഡ് ചെയ്യുക.
2. ഫോണിൽ ഫയൽ ഓപ്പൺ ചെയ്ത് ഇൻസ്റ്റാൾ ചെയ്യുക.
